# AI Home Robot

A progressively developed AI-powered home robot project.

## Project objective

Build a real mobile robot step by step, starting with a functional 4WD platform. New capabilities are only claimed when they have actually been built, programmed and tested.

## Current status

**Current phase:** Phase 1 — 4WD Mobile Robot Platform

### Confirmed progress — 10 October 2026

- 4 motors mounted
- 4 wheels mounted
- Manual wheel rotation checked
- No rubbing against the chassis detected

### Next step

- Install encoder discs
- Install the upper chassis plate

### Not completed yet

- Motor wiring
- Soldering
- Powered motor testing
- Functional encoders
- Arduino programming
- Raspberry Pi integration
- Python motor control

- Autonomous movement

## Main learning reference

Felipe Tambasco — **Building a robot car with Raspberry Pi, Arduino and ROS2 FULL TUTORIAL | Robotics project**

https://www.youtube.com/watch?v=ZjaFtiIQdtA

The tutorial is a learning reference for the base platform. The aim is to understand the fundamentals and later design original extensions.

## Hardware currently available

- Arduino Uno Rev3 SMD
- 2 × L298N motor drivers
- 4WD chassis
- 4 DC geared motors
- 4 wheels
- Encoder discs
- 4 × AA battery holder
- USB-A to USB-B cable
- Dupont jumper wires
- Full-size breadboard
- Official Raspberry Pi 27W USB-C UK power supply
- Raspberry Pi 5 Active Cooler
- YIHUA 926LED III 60W soldering station
